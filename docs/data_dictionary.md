# Data Dictionary

| Column | Meaning | Example source |
|---|---|---|
| player | Player name | NBA Stats / roster source |
| team | Current team abbreviation | NBA Stats |
| age | Player age | NBA Stats / Basketball Reference |
| position | Listed position | NBA Stats |
| minutes | Season minutes played | NBA Stats |
| bpm | Box Plus/Minus or similar advanced impact metric | Basketball Reference |
| usage_rate | Usage percentage | NBA Stats / Basketball Reference |
| social_followers | Combined public followers across selected platforms | Instagram/TikTok/X/YouTube |
| engagement_rate | Average engagement divided by followers | Public social posts |
| posting_rate | Posts per week or month | Public social profiles |
| google_trend | Relative search interest | Google Trends |
| wiki_views | Wikipedia pageviews over selected window | Wikimedia Pageviews |
| media_mentions | News/media mentions over selected window | Google News / GDELT / manual count |
| momentum_growth | Recent growth rate vs previous period | Trends/followers/pageviews |
| endorsement_count | Count of visible brand partnerships | Public web search / player site |
| brand_fit | Manual 1-10 score for sponsor-safe fit | Team rubric |
| risk_score | Manual 1-10 score where higher means more brand risk | Team rubric |

Keep the time windows consistent. Example: use the same 90-day window for search, media, and pageviews.
