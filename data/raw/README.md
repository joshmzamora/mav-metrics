# Raw data

Put sourced public data here.

Start by copying `player_inputs_template.csv` to `player_inputs.csv`, then replace the placeholder rows with real NBA player data.

Suggested sources:
- NBA stats: https://www.nba.com/stats
- Basketball Reference: https://www.basketball-reference.com
- Google Trends: https://trends.google.com
- Wikipedia Pageviews: https://pageviews.wmcloud.org
- Social platforms: public profile follower and engagement counts
- NBA merchandise/news releases for validation

Do not commit private, scraped-without-permission, or paid data.
